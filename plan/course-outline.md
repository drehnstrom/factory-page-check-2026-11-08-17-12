# Course Title: Factory Page Check (1 hour)

## Course Description

Building automated pipelines and web factories requires constant verification that committed steps appear correctly on the local page. Without a systematic check, broken builds and missing assets can go unnoticed.

This course teaches how to verify local pages and confirm that each committed step is correctly listed and rendered. Students explore page verification techniques and hands-on checks using a standard browser.

## Learning Objectives

- Confirm the page lists each committed step
- Understand local page structure and verification methods
- Run browser checks to validate pipeline outputs

## Who Should Attend

The author checking the local page.

## Prerequisites

- A browser

## Hands-On Activities

- Lab: Verifying Local Page Steps

**Module 1: Introduction to Page Verification**
